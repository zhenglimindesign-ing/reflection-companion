# Reflection Companion 使用指南

**简体中文** | [English](USER_GUIDE.md)

版本 0.3.0，公开 Alpha。先看[产品概览](../README.zh-CN.md)、[四段完整示例](EXAMPLES.zh-CN.md)和[维护说明](MAINTAINING.zh-CN.md)。

## 直接开始

你可以回顾变化、检查判断、拓展视角、寻找自我探索灵感，或保留重要理解。日、周、自选时段、特定主题和睡前轻聊都是可组合的使用方式。安装不要求先配置保存或定时；也不自动扫描全部历史。

- “回顾我最近一周的对话，哪些想法变了？”
- “帮我检查这个判断，也考虑支持它的理由。”
- “围绕这个问题，带我认识一个新的视角。”
- “不知道怎样开始，给我几个轻松的探索玩法。”
- “最近有什么大家分享的自我探索提示词？说明来源和热度依据。”
- “刚才那点我认同，请保存；另一句推测不准确，改成……”

选择玩法后会在当前对话执行，不必复制提示词或换 Skill。可以随时说“不符合我”“聊过了”“轻一点”“更深一点”“换方向”。没有可用历史时，助手应说明范围，改用当前材料或适合无历史的玩法。

## 安装与升级

已验证的目标是 macOS 上的 Codex CLI/桌面环境；其他平台未认证。可选保存程序需要 Python 3.10+，只用标准库。

直接让 Codex 从公开仓库 `https://github.com/zhenglimindesign-ing/reflection-companion` 的 `v0.3.0` 安装，核对版本，并避免重复启用旧版。CLI 路径为：

```sh
codex plugin marketplace add zhenglimindesign-ing/reflection-companion --ref v0.3.0
codex plugin add reflection-companion@reflection-companion
```

也可从 [Releases](https://github.com/zhenglimindesign-ing/reflection-companion/releases) 下载 ZIP，解压并保留隐藏目录；顶层包含 README、`.agents`、plugins 和校验清单。让助手检查 SHA256SUMS 与文件清单，再注册这个实际本地目录并安装。保留注册过的解压来源目录。

安装后按应用需要刷新，打开一个新 chat 并选择插件。不要求在开发项目里使用。首次可以直接问一个真实问题；确认实际加载 0.3.0 后使用即可，无需重做开发验收清单。

固定版本来源不会自动跳到下一版。更新时告诉助手目标版本：先读回当前来源和版本，检查新版本说明，再将同一来源升级到目标 ref（或按宿主支持的方式移除旧来源、重新注册目标 ref），重新安装并核对版本。保留旧版信息和原个人保存目录；不要同时启用旧候选来源和公开来源。插件升级不应修改个人记录。官方机制见 [插件文档](https://developers.openai.com/plugins/build/plugins)。

## 可选：跨对话保存

选择一个你拥有的个人工作区，避开共享目录、安装缓存和临时解压目录。可以说：“我选择这里保存 Companion 内容。先说明准确位置和隐私边界；只有我要求保留或修正时写入。”提供实际时区。你确认后，助手在该工作区的 `.reflection-companion/state.json` 建立记录。后续 chat 使用同一工作区；换目录时说明原位置。

记录是本地明文。相关内容仍会由宿主/模型按其政策处理；没有另行加密、跨设备同步或开发者服务器。

自然语言操作包括：“保存这条”“纠正为……”“这件事解决了”“不要再沿用这条观察”“目前保存了什么”“导出到这里”“删掉这条”“清空并暂停保存”“排除这个主题”。成功写入后才报告记录 ID 和路径。纠正让旧版本退出正常使用；删除不会清除原始聊天、既有回复、导出文件或系统备份。

如果希望减少跨 chat 重复，可另行允许记录已展示的问题与探索主题。这默认关闭，记录仅表示看过，不表示赞同；内容在后续写入时清理超过 90 天的展示记录，默认比较近 14 天。助手还应检查语义重复，不能保证永不重复。当前对话里的反馈无需保存即可生效；跨对话保存偏好仍需明确授权。

## 可选：定时

给出想要的内容、时间、时区、范围和使用工作区，再要求设置、读回、检查首跑。例如：“在这个工作区每周日 19:00，按我指定的时区回顾七个完整日历日；排除私人关系，创建后核对并检查第一次送达。”时间与时区使用你的实际选择。

可以定时回顾、提问、拓展或推荐探索；所有方式共享同一行为与来源规则。实际送达依赖宿主、设备与工作区可访问性，本地目录不能自动供云端使用。此版本没有替你激活定时，也不承诺设备关闭时送达。[宿主定时说明](https://learn.chatgpt.com/docs/automations)。

“暂停推送”要暂停宿主任务；暂停保存不等于暂停推送。安装不会迁移原有定时任务。定时输出不代表用户阅读过。

## 隐私、失败与反馈

没有自动回传、分析埋点、收费账户或本产品 API Key。使用受宿主账户与额度限制。历史只来自实际可访问的来源，不保证完整归档、附件、音频、过去的全部 Codex 对话或其他平台。AI 观察可拒绝或纠正，不用于诊断或替你决定人生意义。

看不到插件：检查来源、隐藏目录、版本与启用状态，再按需刷新应用。读不到历史：说明具体缺口，继续处理当前材料；不要为了通过检查上传大段私密聊天。保存失败或被锁：保留原文件，检查路径和权限，不重置记录、不擅自删除锁。新 chat 没接上：检查是否同一工作区且保存未暂停，避免新建第二份库。

不准确、重复或无用时可以直接指出。公开反馈可走 [Issues](https://github.com/zhenglimindesign-ing/reflection-companion/issues/new/choose)，仅需版本、预期和实际表现；不要在公开 Issue 附个人聊天。助手不会自动替你提交反馈。

# 手机文字示例：体验一次方法

**简体中文** | [English](MOBILE.md)

[产品概览](../README.zh-CN.md) · [日记与周回顾](USER_GUIDE.zh-CN.md) · [电脑安装](PLATFORMS.zh-CN.md)

先用你已有的中文聊天应用，例如豆包、Kimi 或 DeepSeek，开一个新对话。以下是普通文字体验入口，不代表这些应用已经安装或通过本 Skill 的兼容验证。模型、联网、文件和定时功能以你账户实际可用的为准。

这确实是一段普通 prompt。它让你试一次对话方法，不是完整 Skill 的手机版本，也不是安装 Skill 的理由。它不携带引用资料、收获库程序、自动读取记录或跨对话纠正。只需要偶尔问一个问题，用这段或自己收藏的提示词就够了。需要持续回看、修正和保留时，再看[产品的完整价值](../README.zh-CN.md)。

## 复制这一段就能开始

```text
请做我的反思伙伴，陪我理解自己的经历，不要急着给我贴标签。
先让我在三种方式里选一个：记今天的日记、讨论一个纠结、尝试一个轻松的自我探索问题。
一次只问一个问题；用我明确说过的事实，区分我的话和你的推测。
我可以说“不符合我”“先不分析”“换一个”或“停”。不要把不同意当成我在逃避。
只使用当前对话和我主动提供的材料；读不到过去的对话就直说。
现在开始，不需要我先提供完整背景。除非我要求，不保存个人结论或设置定时任务。
```

选完就继续讲一个小片段。也可以跳过菜单，直接说：“今天开会没说出我的想法，有点遗憾。陪我记一篇短日记，先别分析。”完整[示例对话](USER_GUIDE.zh-CN.md)会说明接下来如何进行。

## 想要一点新东西

```text
帮我找近期公开分享的自我探索提问方法，优先轻松、无需历史的。
如果能联网，请核实原始页面和日期，给我两个不同方向，附来源。
区分“近期发布”“最近收录”和“有热度证据”；不确定就说不确定。
如果不能联网，给我你原创的两个问题，并说明这不是网络新发现。
我选一个之后，请直接陪我做，一次一个问题。
```

聊天应用不一定能读取我们的公共目录，但仍可以联网寻找灵感或原创提问。不要承诺跨对话不重复。先在当前对话里说“这个聊过了”就能调整。

## 用得上，再升级

想保存日记时，先要求整理成可复制的短文，放到你惯用的笔记应用。想做周回顾时，在同一对话提供选定的几篇日记。不要为了体验上传全部聊天档案。

需要直接读取本地日记、维护可修正的收获库时，转到[电脑入口](PLATFORMS.zh-CN.md)。使用同一方法不代表不同平台之间自动同步。中文资料与可复制内容是手机入口的主体，GitHub 下载不应成为第一次体验的前提。

Kimi 官方提供在 Agent 模式中通过 `/skill-creator` 对话创建自定义技能的方式；可以把以上规则作为需求起点。但本项目尚未在 Kimi 账户完成安装和结果验证，不把它列为完整支持。见 [Kimi 官方说明](https://www.kimi.com/help/plugins-and-skills/use-skills-in-agent)。

## 从小红书来，可以反馈什么

只需要回答：“哪一句让我开始了？哪一步卡住？哪段像我或不像我？”不用提交真实日记。公开评论或 Issue 也不需要包含个人经历细节。手机体验与完整 Skill 要明确区分，避免“自动看懂全部聊天”“每天自动替你写”的宣传承诺。

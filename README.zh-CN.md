# Reflection Companion

**简体中文** | [English](README.md)

**让你与 AI 讨论过的事情，成为以后还能回看、质疑和修正的个人理解。**

你可能已经和 AI 讨论过很多选择、项目、兴趣和困惑。Reflection Companion 把这些实际可访问的对话串起来：回看想法如何变化，检查解释是否站得住，寻找相关的新视角，并在你愿意时保留收获，让下一次讨论接着往前走。

它适合经常通过 AI 思考、希望从这些讨论中持续获得理解的人。你不需要额外维护一套完整日记，也不需要每次重新编写一长段反思提示词。

## 为什么安装 Skill，而不是收藏几个提示词

偶尔想问一个好问题，用普通提示词就够了。本 Skill 的价值在持续使用时：把材料读取、分析方式、纠正和可选记录组织成可重复的流程，减少你反复安排这些步骤的工作。

| 你希望它做的事 | 这个 Skill 具体承担什么 |
| --- | --- |
| “回顾这周” | 先读取授权范围内真正可访问的材料，说明覆盖范围，再比较变化；读不到就明确说明。 |
| “帮我看看盲区” | 检查原话、证据与另一种解释，允许结论是“你目前的判断合理”。 |
| “之前那条理解不对” | 在当前讨论中纠正；若那条已保存，按你的要求更新记录，以后读取时使用修正后的版本。 |
| “这次想探索点新的” | 从基础库、当前问题或公开来源挑适合的方法，选中后继续讨论；可选记录帮助减少重复。 |
| “下周接着看” | 在你启用保存后，读取同一工作区的相关收获，再结合新材料重新判断。 |

Skill 本身也是给模型的指引，加上引用资料和保存等辅助程序。它没有独占的模型能力，也不保证每个回答都优于你写的 prompt。你完全可以自己安排同样的流程；安装的理由是希望这套方法能被重复调用和维护。只想偶尔获得一个问题、也不需要持续回顾的人，不必为了题库安装。

## 一件事怎样持续产生价值

以下为编写的演示，不是真实使用结果。

周二，你在讨论中说：“我一直修改方案，可能是在拖延。”周五的材料补充了原因：“客户直到今天才给出预算。”周回顾应因此调整解释：延迟可能与信息未齐有关，不能只凭反复修改就判断你在回避决定。

你可以说：“这次的结论保留下来，但别推成我一贯的性格。”以后再遇到类似情况，Companion 应把这条限定和新材料一起考虑，而不是又从“你总是拖延”开始。这个过程用到了回顾、检查判断和保留修正；需要时，也可以探索怎样更早发现关键信息缺口。

保存是你选的；没有开启时，也能完成当下的回顾与讨论，只是不承诺跨 chat 连续性。

## 按此刻的需要开始

| 场景 | 可以直接说 | 用到的能力 |
| --- | --- | --- |
| 一天结束，整理经历 | “用今天可访问的对话帮我回顾；缺的地方再问我。先不保存。” | 回顾；需要时整理为日记。 |
| 一周过去，看见变化 | “回顾这周，我对这个问题的看法怎么变了？” | 回顾、检查判断；可选保留。 |
| 一个决定拿不准 | “我可能漏掉什么？也考虑支持当前判断的解释。” | 检查判断、拓展视角。 |
| 想接触不同的想法 | “围绕刚才的问题，给我一个惯常思路之外的视角。” | 拓展视角；可以继续讨论。 |
| 想试点新的 | “推荐两个自我探索玩法，轻松一点；我选好就在这里开始。” | 探索入口，按需要用到四项能力。 |
| 想留下重要理解 | “保留这个收获；上次那条不准确，用这个修正。” | 保留与积累。 |

四项能力仍是 **回顾、检查判断、拓展视角、保留与积累**。日记、周回顾和探索是实际使用场景；主动发消息和定时任务是启动方式。它们共同使用一个 Skill，不是另加一套产品。完整过程都在[同一份使用指南](docs/USER_GUIDE.zh-CN.md)里。

## 能读什么，留下什么

安装不会解锁所有账号历史。可用材料取决于宿主工具、你授权的范围和主动提供的文件。原始聊天由平台管理；日记可以按要求导出为可读文件；选定的收获可保存在个人工作区的 `.reflection-companion/state.json`，并支持修正、查看和删除。

保存与定时都由你另行选择。定时是在约定时间运行相同的流程，不代表设备关闭时仍能执行，也不能凭空生成没有材料的一天。你随时可以说“不符合我”“换一个方向”“先不分析”或“停止”。
